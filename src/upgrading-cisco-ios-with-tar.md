# Upgrading Cisco IOS with tar

This is used on older gear, in the example this is a C3560CX running 15.2 code.

1. Copy the tar from Cisco's site to the box. Do not modify it.

   ```console,editable
   copy http://grove.haske.org:8990/c3560cx-universalk9-tar.152-7.E14.tar flash:
   ```


1. Use the archive command to unpack the tar. This will also expand any html files for the web GUI.

   ```console,editable
   archive download-sw flash:c3560cx-universalk9-tar.152-7.E14.tar
   ```
